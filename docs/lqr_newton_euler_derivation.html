1. 要不要单独加车轮质量？

不算复杂，但分两层理解：

处理方式含义复杂度
车轮质量并入总质量 M 轮心在轮轴上（z=0），只增加平移质量 低
车轮滚转转动惯量 J 轮子自转带来额外动能 → 等效增加 J/r² 到 x 方向惯性 中（多一项，不耦合 pitch）
每个零件单独 6-DOF 大角度、悬架、打滑等 高（本课程不需要）
结论：把轮子质量算进 M，再额外加滚转惯量项 J/r²，是工业界常用的平面 2-DOF 模型。 脚本默认 --include-wheel-spin；初学可 --no-include-wheel-spin 对比差异（对本车 J 很小，影响约 7% 有效质量）。

2. 建模假设与坐标系

与 URDF 一致：x 前、y 左、z 上；base_link 原点在轮轴中点。

  • 广义坐标 q = [θ, x]T：θ 为 pitch（前倾为正），x 为轮轴水平位移 [m]
  • 小角度：sin θ ≈ θ，cos θ ≈ 1
  • 无打滑：轮地接触力 F = τ/r（τ 为单轮力矩 [N·m]）
  • 左右轮同力矩，只分析纵向平衡（偏航由 yaw_loop 单独处理）
  • 控制输入 u = τ，与现有 wheel_effort_controller 一致

LQR 状态（与 balance_lqr.py 对齐）：

xstate = [ θ, θ̇, x, ẋ ]T

代码里 wheel_position 是轮角 [rad]，代入 LQR 时需 x = r · wheel_position [m]，或相应调整 Q 矩阵单位。

3. 高中物理 → 拉格朗日的底层原理

拉格朗日力学不是凭空来的，它把你在高中学过的守恒与功–能关系推广到「多个耦合坐标」的系统。自平衡小车恰好是一个 2 自由度、有重力势能、又有电机注入能量的典型例子。

3.1 动量守恒（牛顿第二定律的积分形式）

质点：动量 p = m v，合力等于动量变化率：

F = dp/dt = m a   （质量不变时）

孤立系统合外力为零 → 总动量守恒。自平衡车不是孤立系统：地面给轮子摩擦力、电机给力矩，所以车体动量和轮子动量都在变——这正是控制要管理的对象。

牛顿–欧拉法（§4）直接对每个部件写 F=ma、τ=Iα；拉格朗日法（§5）则先写能量，再一次性得到耦合方程。

3.2 功与动能定理（能量方法的起点）

合力对位移做的功等于动能变化：

Wnet = ΔK

电机力矩 τ 在角位移 dφ 上作功 dW = τ dφ，通过轮地接触转化为车体的平动与倾倒动能。因此平衡控制本质上是在持续注入或吸收机械能，把不稳定平衡点「钉」在竖直附近。

3.3 机械能守恒（何时成立、何时不成立）

只有保守力（如重力）做功、且没有摩擦/电机等非保守力时：

E = K + V = 常数   （机械能守恒）

倒立摆竖直平衡是势能极大、动能可为零的不稳定平衡点：微扰后重力矩使它倒下，机械能会在 K、V 之间交换但不会自动守恒为定值——除非没有摩擦且你不控制。加入 LQR/PD 后，电机相当于非保守力源，持续修正能量分配。

与控制的联系：开环不稳定（特征值在虚轴上）意味着「只靠守恒律无法停在竖直」；闭环控制通过 τ 打破自由演化，相当于实时调节 ΔK 与 ΔV。

3.4 从能量标量到拉格朗日量 L = T − V

对保守部分，引入：

  • T(q, q̇)：动能，依赖广义坐标 q 及其变化率
  • V(q)：势能，只依赖位形（重力 → 与 θ 有关）
  • L = T − V：拉格朗日量

欧拉–拉格朗日方程（非保守力用广义力 Q 表示）：

d/dt ( ∂L/∂q̇i ) − ∂L/∂qi = Qi

当 Q=0 且 T、V 不显含 t 时，可推出 Noether 意义下的守恒量（如循环坐标对应动量守恒）。自平衡车有电机 → Q ≠ 0，但方程结构仍由 T、V 决定，这是拉格朗日法比「逐个画受力图」更系统的原因。

3.5 为何自平衡车适合用拉格朗日？

高中/牛顿思路拉格朗日思路
对车体、轮子分别画力、列矩选 q=[θ,x]，写 T、V，两步 E-L 方程
约束（无打滑 ẋ=rφ̇）需单独处理选 x 为坐标，滚转动能 ½J(ẋ/r)² 自然进入 T
耦合项 M l θ̈ 容易漏交叉项来自 T 中 ẋ·θ̇，自动出现在 Mmat 非对角元

4. 牛顿–欧拉方程（矢量法）

4.1 受力分析（pitch 方向）

绕轮轴（y 轴）对整机取矩。质心在轴上方高度 l，重力 Mg 产生恢复力矩（小角度）：

τg ≈ −M g l · θ

电机对车体反力矩（轮对车）：−τ（与关节力矩方向相反）。

Iaxle θ̈ + M l ẍ = −M g l · θ − τ

其中 Iaxle 为绕轮轴的 pitch 转动惯量，M l ẍ 为质心水平加速度的耦合项（拉格朗日推导见 §5.4）。

4.2 受力分析（水平方向）

地面对轮的水平力 F = τ/r 推动整机等效质量加速。考虑轮子滚转动能后，x 方向等效质量增大：

M l θ̈ + ( M + J/r² ) ẍ = τ / r

J = 两轮绕滚转轴转动惯量之和。对本 URDF 实心圆柱：J = 2 × ½ mw r² = mw r²（单轮质量 mw）。

§4 与 §5 结论相同：同一物理，两种列式。建议先读 §5 理解能量从哪来，再用 §4 对照受力直觉。

5. 拉格朗日法逐步推导

广义坐标 q = [θ, x]T（与 §2 一致）。以下逐步展开，不跳步。

5.1 写出各部件速度（小角度）

质心水平速度（相对地面）：

vcom,x ≈ ẋ + l θ̇

轮心水平速度为 ẋ；轮子角速度（无打滑）ω = ẋ/r。

5.2 动能 T —— 展开与合并

① 整机质心平动（质量 M，质心水平速度 vcom,x ≈ ẋ + l θ̇）：

Ttrans = ½ M (ẋ + l θ̇)² = ½ M ẋ² + M l θ̇ ẋ + ½ M l² θ̇²

② 绕轮轴 y 的刚体转动（电池、主板等相对质心的转动，合成 Iaxle，由 URDF 平行轴定理累加）：

Tbody,rot = ½ Iaxle θ̇²

③ 两轮滚转（ω = ẋ/r，两轮转动惯量之和 J）：

Twheel = ½ J (ẋ/r)²

三项相加，按 θ̇²、θ̇ẋ、ẋ² 归类系数，得到 2×2 质量矩阵：

T = ½ [ θ̇, ẋ ] Mmat [ θ̇, ẋ ]T
Mmat = [ M l² + Iaxle    M l ;   M l    M + J/r² ]

其中 M l θ̇ ẋ 交叉项来自 Ttrans 展开——车体倾倒会改变质心水平速度，这是 pitch 与 x 耦合的物理根源。J/r² 项说明：轮子越「重」或惯量越大，同样 ẋ 下储存的滚转动能越多，等效于 x 方向更难加速。

5.3 势能 V —— 重力

小角度下质心竖直抬升 Δz ≈ l(1 − cos θ) ≈ ½ l θ² 可等价写成：

V = M g l (1 − cos θ) ≈ ½ M g l θ²

常数项 ½Mgl·0 略去，只保留与 θ 有关部分。x 不出现在 V 中（水平面无势能梯度）。

5.4 拉格朗日量 L 与广义力

L = T − V = ½ [θ̇, ẋ] Mmat [θ̇, ẋ]T − ½ M g l θ²

电机力矩 τ：对车体俯仰的广义力 Qθ = −τ（轮对车的反力矩）；对水平坐标 x，地面摩擦力 F = τ/r → Qx = τ/r。

5.5 对 θ 用欧拉–拉格朗日方程

先求偏导：

∂L/∂θ̇ = Mmat,11 θ̇ + Mmat,12 ẋ = (M l² + Iaxle) θ̇ + M l ẋ
d/dt(∂L/∂θ̇) = (M l² + Iaxle) θ̈ + M l ẍ
∂L/∂θ = −M g l θ

代入 E-L：

(M l² + Iaxle) θ̈ + M l ẍ + M g l θ = Qθ = −τ

移项即 §4.1 的 pitch 方程。

5.6 对 x 用欧拉–拉格朗日方程

∂L/∂ẋ = Mmat,21 θ̇ + Mmat,22 ẋ = M l θ̇ + (M + J/r²) ẋ
d/dt(∂L/∂ẋ) = M l θ̈ + (M + J/r²) ẍ
∂L/∂x = 0

代入 E-L：

M l θ̈ + (M + J/r²) ẍ = Qx = τ/r

即 §4.2 的水平方程。两条 E-L 方程与牛顿–欧拉完全一致。

5.7 写成矩阵并解加速度

Mmat [ θ̈ ; ẍ ] = [ −M g l θ − τ ; τ/r ]

令 aij = Mmat,ij，det = a11a22 − a12a21，用克莱默法则或矩阵求逆得 θ̈、ẍ —— 结果即 §6 的 cij 与 A、B 矩阵。

6. 小角度线性化与 2×2 质量矩阵

写成矩阵形式：

[ a11   a12 ] [ θ̈ ] = [ −M g l · θ − τ ]
[ a21   a22 ] [ ẍ ]    [        τ/r       ]

其中：

a11 = M l² + Iaxle,   a12 = a21 = M l,   a22 = M + J/r²

令 det = a11a22 − (M l)²，解加速度：

θ̈ = c11 θ + c12 τ,    ẍ = c21 θ + c22 τ
c11 = −a22 M g l / det
c12 = (−a22 − a12/r) / det
c21 = a21 M g l / det
c22 = (a21 + a11/r) / det

开环 pitch 模态应不稳定（特征值纯虚数 ±jω），本车算例 ω ≈ 11.7 rad/s。

7. 状态空间 A、B

由 ẋstate = A xstate + B u，u = τ：

A = [ 0   1   0   0 ;   c11   0   0   0 ;   0   0   0   1 ;   c21   0   0   0 ],    B = [ 0 ; c12 ; 0 ; c22 ]

这是4 阶、单输入模型：pitch 不稳定模态 + 平移积分链。LQR 一次算出平衡 + 位置/速度跟踪增益（方案 B）。

8. LQR：Riccati 与 K

8.1 离散化（控制周期 200 Hz → dt = 0.005 s）

xk+1 = Ad xk + Bd uk

有 scipy 时用零阶保持（ZOH）；否则脚本用一阶欧拉近似。

8.2 离散代数 Riccati 方程（DARE）

P = Q + AdT P Ad − AdT P Bd ( R + BdT P Bd )−1 BdT P Ad

P 为中间量；实际控制增益：

K = ( R + BdT P Bd )−1 BdT P Ad

8.3 参考跟踪

τ = −K ( xstate − xref )

符号若与 Gazebo/URDF 相反，用 yaml 中 lqr_output_sign: -1.0 翻转，不要硬改 K 的符号。

10. 脚本用法（方式 B：调参 / 运行分离）

文件用途
